## 👋 About me

I'm **Hanahira**, a self-taught developer from the **HanahiraNetwork** side of the internet.
Most of what I build is small, fast and runs on my own hardware — web services on **Bun + Hono**,
front-ends on **Vite + TypeScript**, everything wrapped in **Docker** and talking to **MySQL**.

```ts
const hanahira = {
  handle:   "KBYSHanahira",
  org:      "HanahiraNetwork",
  site:     "https://hanahira.dev",
  runtime:  "Bun",
  stack:    ["TypeScript", "Hono", "Vite", "MySQL", "Docker"],
  alsoInto: ["C++", "Arduino", "Stable Diffusion tooling"],
  motto:    "Ship it small, ship it self-hosted.",
} as const;
```

- 🌱 Currently deepening — **Hono middleware, MySQL indexing, container-first deploys**
- 🧰 Daily driver — **Linux + Docker Compose**, host-network containers, `ufw` in front
- 🤝 Happy to talk about — self-hosting, Bun/Hono APIs, ComfyUI & Civitai tooling
- 📫 Reach me — [hanahira.dev](https://hanahira.dev/) · [@HanahiraDev](https://x.com/HanahiraDev)
